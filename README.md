**Deskripsi Project** 
Perkembangan teknologi Internet of Things (IoT) telah memberikan dampak 
signifikan dalam berbagai bidang, salah satunya di sektor pertanian. Budidaya 
tanaman melon membutuhkan pengelolaan irigasi yang tepat dan konsisten agar 
tanaman dapat tumbuh secara optimal. Namun, proses pemantauan dan 
penyiraman yang masih dilakukan secara manual sering kali kurang efisien dan 
memerlukan waktu yang cukup besar. 
Oleh karena itu, diperlukan sebuah sistem Smart Farm berbasis IoT yang mampu 
membantu petani dalam memantau kondisi lahan serta mengelola irigasi secara 
otomatis dan jarak jauh. Sistem Smart Farm Melon ini dirancang untuk 
memberikan kemudahan monitoring dan kontrol melalui aplikasi berbasis web dan mobile 
sehingga petani dapat mengakses informasi kapan saja dan di mana saja.



**Fitur utama aplikasi Meloners SmartFarm**

1. Login pengguna untuk akses dashboard.

2. Dashboard monitoring real time, menampilkan suhu, kelembaban udara, kelembaban tanah, intensitas cahaya, pH, dan status perangkat.

3. Kontrol irigasi otomatis berdasarkan ambang batas kelembaban, termasuk status ON atau OFF.

4. Kontrol manual perangkat

5. Penjadwalan penyiraman, pemberian nutrisi, dan pencahayaan.

6. Riwayat data sensor, lengkap dengan grafik historis.

7. Manajemen data tanaman, termasuk detail tanaman yang dikelola.

8. Manajemen perangkat IoT, termasuk status online atau offline.

9. Pengaturan sistem, seperti pengaturan threshold  dan notifikasi. 

10. Informasi profile pengguna
